# 그리드시티 (GridCity)

브라우저에서 바로 하는 도시 건설·국가 경영 시뮬레이션 게임입니다.
도로를 깔고 구역을 지정해 도시를 키우고, 의회와 외교, 방공, 금융 시장까지 직접 운영합니다.

설치할 것이 없습니다. `index.html` 파일 하나로 실행됩니다.

## 실행 방법

**내 컴퓨터에서**

1. 이 저장소를 내려받습니다.
2. `index.html`을 브라우저로 엽니다.

**GitHub Pages로 배포**

1. 저장소 **Settings → Pages**로 갑니다.
2. Source를 `main` 브랜치의 `/ (root)`로 정하고 저장합니다.
3. 잠시 뒤 `https://<사용자 이름>.github.io/<저장소 이름>/`에서 열립니다.

글꼴은 Google Fonts에서 불러오므로 인터넷에 연결되어 있어야 의도한 모양으로 보입니다. 연결이 없어도 기본 글꼴로 게임은 됩니다.

## 주요 기능

### 도시 건설
- 80×80 칸 등각 투영 지도, 지형 올리기·내리기·평탄화
- 일반 도로, 대로, 고가도로, 인터체인지 램프, 철도, 버스 정류장, 기차역
- 주거·상업·공업 구역과 세부 산업 구역 (농업, 중화학, 첨단 산업, 물류)
- 전력, 수도, 치안, 소방, 교육, 의료, 공원
- 랜드마크 26종, 항구, 공항
- 오염, 땅값, 교통량, 서비스 범위를 보여 주는 정보 보기

### 국정 운영
- **의회**: 다섯 정당이 100석을 나눠 갖고, 2년마다 선거를 치릅니다. 법안 표결, 야당 설득, 연립 정부 구성이 가능합니다.
- **법률과 국가 정책**: 징병법·경제법·무역법과 국가 정책 21개
- **외교와 전쟁**: 12개 나라와 관계, 무역, 동맹, 선전포고, 휴전 협상
- **세계 지도**: 도시마다 절차적으로 생성되는 대륙, 기후대, 산맥, 강

### 방공
- 위협 세 종류: 드론, 순항 미사일, 탄도 미사일
- 레이더 탐지 → 지휘망 연동 → 포대 요격 → 탄약 보급으로 이어지는 교전 체계
- 대공포, 지대공 미사일, 방공 사령부, 레이저 방공포
- 전력이 끊기거나 요격탄이 떨어지면 방공망이 약해집니다.

### 국방 연구와 무기 설계
- 실제 무기 체계를 본뜬 기술 43개 (천궁, 패트리어트 PAC-3, L-SAM, 사드, 현무, KF-21 등)
- 모든 연구를 마치면 **무기 설계국**이 열립니다. 부품 46종을 네 칸에 조합해 요격 미사일, 타격 미사일, 무인 전투 체계를 직접 설계합니다.

### 금융 시장
- 주식과 ETF 27종 (개별주, 레버리지, 인버스, 안전자산 포함)
- 채권 6종: 매달 이자 지급, 금리 변동에 따른 가격 변화, 부도 위험
- 선물 6종: 증거금 거래, 일일 정산, 강제 청산
- 옵션: 콜·풋, 만기 3개, 행사가 5개
- 세계 뉴스와 전쟁, 유가가 시세를 움직입니다.

### 화면
- 흑백 중심의 유리 패널 UI, 라이트·다크 테마 자동 전환
- 홀로그램·네온 스타일의 도시 그래픽
- 데스크톱과 모바일 터치 모두 지원

## 조작

| 입력 | 동작 |
|---|---|
| 드래그 | 지도 이동 |
| 마우스 휠 / 두 손가락 벌리기 | 확대·축소 |
| `W` `A` `S` `D` | 지도 이동 |
| `Space` | 일시정지 |
| `1`~`9` | 건설 분류 선택 |
| `0` | 철거 |
| 칸 누르기 | 건물·땅 정보 보기 |

## 저장과 불러오기

- 진행 상황은 브라우저에 자동으로 저장됩니다.
- **메뉴 → 파일로 저장**을 누르면 `.json` 저장 파일을 내려받습니다.
- 다른 기기에서는 **메뉴 → 파일 불러오기** 또는 시작 화면의 **저장 파일 불러오기**로 그 파일을 올리면 이어서 할 수 있습니다.

### 테스트용 저장 파일

`gridcity_test_save.json`은 기능을 빠르게 살펴보기 위한 저장 파일입니다.

- 인구 약 3만 명, 자금 $5,000,000
- 모든 건물 해금, 국방 연구 전체 완료, 무기 설계국 사용 가능
- 방공 포대, 의회, 국민연금 기금이 준비된 상태

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 게임 전체. HTML, CSS, JavaScript가 한 파일에 들어 있습니다. |
| `gridcity_test_save.json` | 테스트용 저장 파일 (선택) |
| `README.md` | 이 문서 |

## 기술

- 순수 HTML, CSS, JavaScript. 빌드 도구와 외부 라이브러리가 없습니다.
- 지도는 Canvas 2D로 그립니다.
- 저장은 브라우저의 `localStorage`와 JSON 파일을 씁니다.

## 알려진 제한

- 브라우저 저장 데이터를 지우면 자동 저장도 함께 지워집니다. 중요한 도시는 파일로 저장해 두세요.
- 화면 전체에 빛 번짐 효과를 쓰기 때문에 사양이 낮은 기기에서는 느릴 수 있습니다.
